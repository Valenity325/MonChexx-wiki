MonChexx Patch Notes: Skill Attack Rules

Season 1 · Update 09 · November 1

Battle rules

  • Damage based on Skill Power is still not an attack, except where the skill text says it is an attack.
  • Fixed an issue where using a skill that attacks did not count for "each attack" and "every N attacks" effects. A skill that attacks now counts as one attack each time it is used.

Plushie changes

Flamo

  • Ember Fist: The first damage it deals is now an attack. The Burn damage is still not an attack.

Mouseball

  • Sawtooth Cannon: Now an attack. It stays physical damage based on Skill Power at the same ratio.
  • Fixed Aim: The range it gains while standing still now applies to Sawtooth Cannon too, not only to basic attacks.

Optimouse

  • Laser Cannon: The damage is now based on Skill Power instead of Attack. It stays magic damage at the same ratio, and is no longer an attack.
