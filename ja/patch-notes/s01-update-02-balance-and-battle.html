MonChexx パッチノート：バランス調整 · 戦闘システム

シーズン1 · アップデート02 · 10月16日

戦闘システム

  • ほぼすべてのスキルのダメージ・回復・シールドが、攻撃力、魔力または最大HPに比例するように変更されます。今後は、ぬいぐるみのレベルが上がるとスキルも強くなります。
  • すべてのぬいぐるみのHPが2倍になります。通常攻撃は攻撃力の100%のままで、スキルの数値が大きく上がります。
  • やけどと毒は、1秒ごとではなく、効果時間全体にわたって分けてダメージを与えるようになります。以下のやけど・毒の数値は毎秒のダメージです。
  • サドンデスの開始が25秒 → 20秒に、引き分けの判定が35秒 → 30秒に変更されます。
  • 射程2マス以上のぬいぐるみの最大マナが40 → 60、50 → 75に変更されます。
  • ほかのぬいぐるみに送るスキルとパッシブは、対象に届いた瞬間に適用されるようになります。飛んでいく速さはスキルごとに異なります。
  • マナが満タンのぬいぐるみは、通常攻撃より先にスキルを使うようになります。攻撃速度が速いぬいぐるみも、スキルが後回しになりません。
  • すべてのぬいぐるみのバランスを、Lv.11を基準に再調整しました。

ぬいぐるみ別の変更

ボニス

  • ボーンシールド：周囲1マス以内に敵がいなくても、マナがたまれば使うようになります。シールド量が最大HPの10% → 最大HPの15% + 魔力の270%に、挑発時間が1秒 → 1.5秒に変更されます。

ボニックス

  • ツインボーンラッシュ：一撃目のダメージが攻撃力の230% → 625%に、二撃目のダメージが400% → 1245%に変更されます。
  • バーサクボーン：失ったHP1%ごと（変更前：2%ごと）に攻撃速度が1%上がるようになり、上限が40% → 80%に変更されます。

フラモ

  • 火の粉パンチ：ダメージが魔力の580% → 1000%に、やけどが毎秒魔力の260% → 480%に、やけどの効果時間が4秒 → 2秒に変更されます。このやけど状態で倒れた敵は爆発し、周囲2マス以内の敵に、倒れた敵の最大HPの13%分の魔法ダメージを与えるようになります。
  • 残り火：やけど状態の敵を通常攻撃したとき、フラモが付与したやけどの残り時間が2秒未満なら2秒に延びるようになります。マナを25獲得する効果は削除されます。

フラモニクス

  • フェニックスダイブ：やけどが毎秒魔力の115% → 245%に変更されます。
  • 残り火：フラモと同様に変更されます。
  • 最大マナが40 → 60に変更されます。

ハイドリス

  • 水の道：回復量が魔力の180% → 580%に、連鎖範囲が1マス → 2マスに変更されます。連鎖するたびに、直前の回復量の50%を回復するようになります。
  • 押し寄せる海流：直接ダメージを受けると、周囲1マス以内のすべての敵を1マス押し出すようになります（クールタイム4秒）。これまでは、通常攻撃3回ごとに対象を押し出していました。
  • 最大マナが50 → 75に変更されます。

セレニス

  • 波の道：ダメージが魔力の140% → 620%に、連鎖範囲が1マス → 2マスに変更されます。連鎖するたびに、直前のダメージの50%を与えるようになります。
  • 押し寄せる海流：ハイドリスと同様に変更されます。
  • 最大マナが40 → 60に変更されます。

ボルティス

  • イナズマクロー：射程が3マス → 2マスに、ダメージが攻撃力の600% → 1650%に変更されます。
  • 最大マナが50 → 75に変更されます。

ボルタイガー

  • サンダーハント：ダメージが攻撃力の620% → 2000%に変更されます。

ヴォイドレン

  • 影の奇襲：ダメージが攻撃力の400% → 1450%に変更されます。追加ダメージは、HP35%以下で×1.8から、HP10%以下で×2に変わります。
  • ヴォイドフィースト：獲得マナが5 → 1に変更され、戦闘ごとの最大30までの制限がなくなります。

グラッシー

  • クリスタルバースト：射程が2マス → 1マスに、ダメージが対象には魔力の400% → 1230%、周囲の敵には200% → 615%に変更されます。

メバエドリ

  • サンリーフの祝福：回復量が魔力の150% → 620%に変更されます。
  • タネのシェルター：今後は、タネがコートに立つ木になります。開始マスにタネを植えて隣のマスへ下がります。タネはメバエドリの最大HPの150%分のHPを持ち、敵が壊すことができます。5秒後（変更前：10秒後）から3秒ごと（変更前：1回のみ）に、周囲1マス以内の味方に戦闘開始時の魔力の210%（変更前：160%）分のシールドを4秒間付与します。メバエドリが倒れても、木は残ります。
  • 最大マナが50 → 75に変更されます。

ハニージャム

  • はちみつエール：範囲が2マス → 4マスに、持続時間が6秒 → 4秒に変更されます。自身と最も近い味方ではなく、この戦闘で通常攻撃によるダメージが最も多い自身以外の味方1体だけに効果を与えるようになります。攻撃速度の上昇量は100%のままで、その間、その味方の通常攻撃が命中するたびに、ハニージャムの魔力の200%分の魔法ダメージを追加で与えます。このダメージはハニージャムが与えたダメージとして集計されます。
  • 最大マナが50 → 40に変更されます。

エコーウィング

  • 通常攻撃の射程が3マス → 2マスに変更されます。
  • 耳をつんざく叫び：射程と扇形の長さが3マス → 2マスに、ダメージが攻撃力の80% → 765%に変更されます。スローの代わりに、2秒間防御力を15下げるようになります。
  • 最大マナが40 → 60に変更されます。

ノイズウィング

  • 通常攻撃の射程が3マス → 2マスに変更されます。
  • うつろな叫び：射程と扇形の長さが3マス → 2マスに、ダメージが魔力の70% → 585%に変更されます。
  • 不協和音：説明がより分かりやすくなります。動作は変わりません。
  • 最大マナが40 → 60に変更されます。

コロガメ

  • 石のこうら：防御力の上昇量が80 → 165に、魔法耐性の上昇量が60 → 125に変更されます。
  • はじめのこうら：戦闘開始時のシールドが最大HPの40% → 170%に変更されます。

ドクマイマイ

  • 毒の雲：ダメージが毎秒魔力の260% → 915%に変更されます。
  • 毒のぬめり：毒の跡のダメージが毎秒魔力の30% → 360%に変更されます。

フワコナ

  • ウィングダスト：対象に魔力の445%分の魔法ダメージも与えるようになります。
  • 最大マナが40 → 60に変更されます。

ポポタケ

  • 胞子のいやし：HPが低い味方最大6体の代わりに、周囲1マス以内のすべての味方（自身を含む）を回復するようになります。発動タイミングが0.25・1.25・2.25秒 → 0.25・0.5・1秒に、回復量が魔力の105% → 490%に変更されます。三回目の発動が終わるまで、マナはたまりません。
  • 残り菌糸：毎秒の回復量が各味方の最大HPの2% → ポポタケの最大HPの10%に変更されます。
  • 最大マナが50 → 75に変更されます。

ベルキン

  • 鐘のひびき（新アクティブ）：「シルバーチャイム」に代わります。2マス以内のすべての味方（自身を除く）のマナを50回復します。
  • シルバーベル（新パッシブ）：「はじめのチャイム」に代わります。自身または味方が弱体効果を受けると、そのぬいぐるみの弱体効果をすべて解除し、マナを20得ます。戦闘ごとに1回ではなく、クールタイム5秒になります。
  • 最大マナが50 → 75に変更されます。

チクタクギア

  • タイムスロー：3マス以内で最も近い敵最大3体に魔力の505%分の魔法ダメージを与え、3秒間攻撃速度を50%下げるようになります。これまでは、ダメージを与えずに5秒間通常攻撃の間隔を110%延ばしていました。
  • 通常攻撃をしなくなります。
  • 黄金のゼンマイ：マナ獲得が6秒ごとに10 → 毎秒15に変更されます。
  • 最大マナが50 → 60に変更されます。

プニミトン

  • トンネル奇襲：ダメージが攻撃力の180% → 570%に変更されます。
  • 土のよろい：ダメージ軽減が18% → 20%に変更されます。

クリスタウル

  • 見ぬく目：攻撃力が最も高い敵ではなく、この戦闘で受けたダメージが最も多い敵を狙うようになります。ダメージが攻撃力の105% → 魔力の510%に変更されます。
  • はじめの予知：直接ダメージの増加量が10% → 50%に変更されます。
  • 最大マナが50 → 75に変更されます。

マウスボール

  • ギアキャノン：ダメージが攻撃力の165% → 670%に変更されます。砲弾が対象に届いたときにダメージを与えるようになります。
  • 最大マナが50 → 75に変更されます。

メルティ

  • ミツロウのかべ：消費HPが最大HPの7% → 20%に、シールド量が消費したHPの230% → 125%に変更されます。
  • ミツロウのよろい：最大3体までの制限がなくなります。

戦闘演出

  • スキルが、詠唱したぬいぐるみから飛んでいき、届いた場所で弾けます。ハイドリスとセレニスの連鎖は、ぬいぐるみの間を渡っていく見た目に変わります。
  • パッシブごとに固有の演出が追加されます。
  • マナ獲得の演出が小さなしずくひとつに変わり、ぬいぐるみの周りにだけ表示されます。
  • フラモのやけど爆発、ヴォイドレン・ヴォイドリングの「ヴォイドフィースト」、ボルティスの稲妻、メバエドリの木の演出が新しくなります。
  • オプティマウス・エコーウィング・ノイズウィングの範囲表示はより薄く、連鎖スキル・ヴォイドスキルはより濃くなります。

不具合修正

  • 対象を倒したスキルのヒット演出が表示されなかった問題を修正しました。
  • 方向を決めるスキルの詠唱中に、ぬいぐるみが遠ざかる対象を追って向きを変えていた問題を修正しました。

新しい進化8体は、「進化の波動」のお知らせで確認できます。
