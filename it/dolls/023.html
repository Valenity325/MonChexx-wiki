Regimiele

SupportoTiratore

Chiama piccole api operaie a combattere al suo fianco e le nutre con la pappa reale per curarle e aumentarne la velocità d'attacco.

Abilità

Attiva

Pappa Reale

Ripristina a tutte le proprie api operaie salute pari a 10% della loro salute massima e conferisce loro +200% di velocità d'attacco per 3 s. Poi, se ha meno api operaie del massimo, evoca nelle caselle vuote adiacenti un numero di api operaie pari a 1.

Passiva

Sciame Operaio

Le sue api operaie possono essere al massimo 3. Le loro statistiche crescono con il livello di Regimiele, e gli effetti che scelgono un numero limitato di alleati non le scelgono mai. Ciascuna ape operaia subisce ogni secondo danni magici pari a 4% della propria salute massima. Alla sconfitta di Regimiele le api operaie diventano furiose: i danni che infliggono e quelli che subiscono vengono amplificati del 100%.
